インフル予防接種の費用

本記事にはアフィリエイト広告（PR）が含まれます。紹介した商品を購入されると、当サイトに報酬が入ることがあります。内容は運営者が調べて書いています。

インフルエンザの予防接種は、保険がきかない分、家族の人数と子どもの年齢で総額が大きく変わります。この記事では、厚生労働省のインフルエンザQ&A、医薬品の添付文書情報、大田区・市川市・名古屋市の公式ページを、2026年10月20日時点で確認しました。接種の価格は医療機関ごとに違うため、医療機関の価格を示すのではなく、「1回あたりの価格を仮に置いたとき、助成でいくら変わるか」を式と表で示します。医療上の判断（誰が受けるべきか）は書きません。

この記事でわかること・結論

  1. 健康保険は使えず、原則として全額自己負担。 厚生労働省のQ&A（Q12）の記載で、費用は医療機関によって異なります。支払いを減らせるのは、65歳以上などの定期接種と、自治体の独自助成です。
  2. 13歳未満は2回接種なので、子ども1人で大人の2倍の費用がかかる。 大人2人・子ども2人（どちらも13歳未満）の4人家族は、合計6回です。1回4,000円と仮定すると、助成がなければ24,000円、大田区の助成（1回2,000円）なら16,000円になります。
  3. 助成は「住んでいる自治体・年齢・期間」で決まり、多くは2027年1月31日までが接種期間。 確認した3市区は、いずれも期限が1月31日です。1月12日から受けるなら、2回目の間隔を含めて期限に間に合うかを先に確認してください。

この記事について
  • 数字は2026年10月20日時点の公式ページです。2026年度（令和8年度）の助成内容は、その後に変更されることがあります。
  • 医療機関ごとの接種価格は、医療機関が自由に決めるため載せていません。試算は「1回あたり3,000円・4,000円・5,000円と仮定した場合」の計算例で、実際の価格ではありません。

予防接種の費用の仕組み: 定期接種と任意接種

厚生労働省のQ&A（Q12）は、インフルエンザワクチンの接種は病気に対する治療ではないため健康保険が適用されず、原則として全額自己負担で、費用は医療機関によって異なると説明しています。接種を受ける人は、次の2種類に分かれます。

表1　定期接種と任意接種の違い（2026年10月20日時点）
項目定期接種任意接種
対象65歳以上、60〜64歳で心臓・腎臓・呼吸器の機能またはHIVによる免疫の機能に障害があり、日常生活が極度に制限される方（厚生労働省Q13）それ以外の人（子ども、現役世代など）
回数毎年度1回（厚生労働省ページ）13歳未満は2回、13歳以上は1回または2回（添付文書上）
費用の考え方市区町村が一部または全額を公費で負担する場合がある（Q12）。例: 大田区の自己負担は2,500円（2026年度）全額自己負担。自治体が独自に助成する場合がある（Q12）
確認先お住まいの市区町村、保健センター、かかりつけ医同上。助成のない自治体もある

大田区の65歳以上の定期接種は、2026年度（令和8年度）の自己負担が2,500円、生活保護受給者などは0円です。実施期間は2026年9月24日〜2027年1月31日で、例年より早い流行期入りを理由に開始日を前倒ししたと区のページに書かれています。

接種回数: 13歳未満は2回

厚生労働省のQ&A（Q9）は、13歳未満は2回接種と書いています。1回接種後より2回接種後のほうが抗体価の上昇が高いことが理由とされています。年齢別の量と回数は次のとおりです。

表2　年齢別の接種量と回数（厚生労働省Q&A Q9、2026年10月20日確認）
年齢1回の量回数備考
6か月以上3歳未満0.25mL2回—
3歳以上13歳未満0.5mL2回1回目が12歳で2回目が13歳になっても、12歳として2回目を受けて差し支えない
13歳以上0.5mL添付文書上は1回または2回。健康な成人や基礎疾患のある方の研究では、0.5mLの1回接種で2回接種と同等の抗体価の上昇が得られるとの報告がある定期接種は1回

子どもが2人いて、どちらも13歳未満なら、子どもだけで4回です。費用の試算では「大人の人数＋子どもの人数×2」が接種回数になります。2回の間隔は厚生労働省ページの抜粋に数字がなかったため、記事では書きません。医療機関の指示に従ってください。

自治体の助成の例（大田区・市川市・名古屋市）

2026年度（令和8年度）の助成を、3つの自治体の公式ページで確認しました。同じ「子ども向けの助成」でも、対象年齢・金額・方式がまったく違います。

表3　子ども向けインフルエンザ助成の例（2026年10月20日時点、各自治体の公式ページ）
項目大田区市川市名古屋市
対象生後6か月以上13歳未満は2回まで、18歳（高校3年生相当）以下は1回生後6か月から中学3年生まで。13歳未満は2回まで、13歳以上は1回2026年度中に12歳を迎える方は2回、15歳または18歳を迎える方は1回
助成額（注射）1回につき2,000円（窓口で差し引き）1回につき1,500円（領収書を添えて申請）全額助成（クーポン券を提出）
点鼻（フルミスト）生ワクチンは4,000円、年齢に関わらず1回のみ2歳から中学3年生まで1回、3,000円。注射との併用助成は不可（どちらか一方）2026年度は助成の対象外

名古屋市の助成は全額（無償）ですが、対象は「2026年度中に12歳・15歳・18歳を迎える方」と学年の節目に絞られています。同じ年齢の子でも、生まれた日によって助成の対象になるかどうかが変わります。対象の子にクーポン券が届いていなければ、電子申請で再発行を申請してください（名古屋市のページに再発行の案内があります）。

市川市は2026年度から助成対象を中学3年生まで広げた、と市のページに書かれています。大田区は例年より早く、9月24日から接種開始を前倒ししています。自治体の方針は毎年変わるので、前年の情報を使わず、当年度のページを見てください。

家族4人の総額を試算する

ここでは、大人2人と、13歳未満の子ども2人の4人家族が、全員接種する場合を考えます。接種回数は、大人2回＋子ども4回＝6回です。医療機関の価格は自由なので、1回あたりを3,000円・4,000円・5,000円と仮定し、助成額を差し引いて計算します。実際の価格ではなく、仕組みを見るための計算例です。

表4　家族4人（大人2人・子ども2人、計6回）の自己負担の計算例（1回の価格は仮定）
1回の価格（仮定）助成なし大田区の子ども助成（1回2,000円差し引き）市川市の子ども助成（1回1,500円・後から振込）
3,000円3,000円×6＝18,000円大人6,000円＋子ども(3,000−2,000)×4＝4,000円　合計10,000円18,000円−1,500円×4＝12,000円
4,000円24,000円大人8,000円＋子ども(4,000−2,000)×4＝8,000円　合計16,000円24,000円−6,000円＝18,000円
5,000円30,000円大人10,000円＋子ども(5,000−2,000)×4＝12,000円　合計22,000円30,000円−6,000円＝24,000円

式は「自己負担＝大人の回数×価格＋子どもの回数×（価格−助成額）」です。この計算は、助成額が価格以下のときに成り立ちます。名古屋市のように子どもの分が全額助成の場合は、子ども分が0円になるため、大人2回分だけが自己負担です。ただし名古屋市の対象は12歳・15歳・18歳を迎える学年で、13歳未満の子どもは2026年度中に12歳を迎える子に限られます。

子どもが13歳以上なら回数が変わります。たとえば、小学生（13歳未満）1人と中学生（13歳以上）1人なら、子どもは2回＋1回＝3回で、大人と合わせて5回です。中学生の子は、市川市なら1回分1,500円、大田区なら1回分2,000円（18歳以下は1回）が助成されます。

この表の差は、価格を1,000円ずつ変えるよりも、「助成のある子どもの回数」で大きく動きます。子どもの回数が多い家庭ほど、助成の有無で差が開きます。

家計の他の支出と合わせて、年末年始にかかる費用を把握したい場合は、年末年始の予算の記事も参考にしてください。医療費全般の控除は医療費控除の記事で確認できます。

点鼻ワクチン（フルミスト）の対象年齢と助成

点鼻ワクチンは、注射ではなく鼻に噴霧する経鼻弱毒生ワクチンで、2023年に薬事承認されたと厚生労働省のQ&Aに書かれています。添付文書（医薬品情報データベース KEGG MEDICUS に掲載された用法・用量）では、2歳以上19歳未満の者に0.2mLを1回、各鼻腔内に0.1mLずつ噴霧する、とされています。

表5　注射と点鼻の違い（2026年10月20日時点の公式情報から）
項目注射（不活化ワクチン）点鼻（フルミスト）
対象年齢6か月以上2歳以上19歳未満（添付文書）
回数13歳未満は2回1回（添付文書の用法・用量）
自治体助成の例大田区2,000円・市川市1,500円・名古屋市は全額大田区4,000円・市川市3,000円・名古屋市は2026年度は対象外
厚生労働省Q&Aの記載国内で使われている不活化ワクチンは3価ワクチン薬事承認申請時の資料による発症予防効果は28.8%、接種で発病する頻度は1.8%と記載

点鼻は1回で済むため、13歳未満の子で注射を2回受ける場合と、回数と助成額を並べて比べられます。たとえば市川市で10歳の子が注射を2回受ければ助成は1,500円×2＝3,000円、点鼻を1回受ければ3,000円です。助成額は同じ3,000円でも、窓口で払う価格は医療機関ごとに違います。比べるときは、受ける医療機関に「注射2回と点鼻1回の合計がいくらか」を聞いてください。

厚生労働省のQ&Aは、点鼻の発症予防効果の数字を、薬事承認申請時の資料として載せています。注射との優劣や、どちらを選ぶべきかの判断は、この記事では行いません。持病・アレルギー・体調によっても判断が変わるため、医師に相談してください。

いつ受けるか: 1月12日時点の考え方

厚生労働省のQ&A（Q11）は、インフルエンザは例年12月〜3月頃に流行し、例年1月末〜3月上旬に流行のピークを迎えるとしています。流行状況に応じて、流行を迎える前に接種することが望ましいとも書かれています。公開日の1月12日は、流行期の中ですが、ピークとされる1月末〜3月上旬より前です。

ここで、費用の面から押さえるべき日付は、助成の接種期間の終わりです。確認した3市区はいずれも2027年1月31日でした。1月12日から1月31日までは19日間しかありません。13歳未満の子で2回受けるなら、1回目を早めに済ませ、2回目の予約が期限内に取れるかを、先に医療機関へ聞いてください。2回の間隔は、医師の指示によります。

表6　1月12日に1回目を受ける場合の期限の見え方
自治体の例接種期間の終わり1月12日から期限までの日数申請が必要な場合
大田区2027年1月31日19日窓口で差し引くので申請は不要
市川市2027年1月31日19日申請は2027年2月28日まで
名古屋市2027年1月31日19日クーポン券を持参

判断の分岐: あなたはどれか

  • 65歳以上の家族がいる → 定期接種の対象です。自治体から予診票やお知らせが届いているか、自己負担がいくらかを、自治体の窓口で確認します。大田区の例は自己負担2,500円です。
  • 13歳未満の子どもがいる → 2回接種です。自治体の助成の有無と、2回目まで期限内に受けられるかを先に確認します。
  • 中学生・高校生の子どもがいる → 自治体によって対象が変わります（大田区は18歳以下、市川市は中学3年生まで、名古屋市は12歳・15歳・18歳の節目）。学年で助成の有無が決まります。
  • 子どもの接種で注射が苦手 → 2歳以上19歳未満なら点鼻の選択肢があります。ただし助成の対象かどうか（名古屋市は2026年度は対象外）と、価格を医療機関に確認します。
  • 現役世代の大人だけ → この記事で確認した3市区の助成は、いずれも子どもが対象で、18歳を超える大人の任意接種には出ていません。大人は全額自己負担になる前提で試算し、お住まいの自治体や勤務先の健康保険組合に補助がないかを確認してください。
  • 持病がある・体調に不安がある → 接種の可否や時期は医師の判断が必要です。この記事の情報だけで決めないでください。

手順（6手順）

  1. 家族の年齢を書き出し、65歳以上・13歳未満・13歳以上18歳以下・大人に分けます。接種回数の合計（大人1回、13歳未満2回、など）を出します。
  2. お住まいの自治体名と「インフルエンザ 予防接種 助成 令和8年度」で、自治体の公式ページを探し、接種期間・対象年齢・金額・申請方法を控えます。
  3. 助成の方式を確認します。窓口で差し引く方式（大田区）か、全額を払って後から申請する方式（市川市）か、クーポン券を提出する方式（名古屋市）かで、手元に必要なお金と書類が変わります。
  4. 13歳未満の子がいるなら、受けられる医療機関に電話かWebで、2回の予約を一度に取れるか、2回の間隔と期限（1月31日など）を確認します。
  5. 医療機関に「1回あたりの価格」と「助成を使った窓口での支払額」を聞き、表4の式（大人の回数×価格＋子どもの回数×（価格−助成額））で家族全員分の合計を出します。
  6. 接種当日は、母子健康手帳・保険証や医療証・予診票・クーポン券・（後払いなら）領収書の保管を確認して受けます。領収書は、助成の申請や医療費の確認に使えるので、捨てずにまとめて保管します。

よくある失敗4つと回避策

  1. 13歳未満の子を1回で終わらせてしまう。 厚生労働省のQ&Aでは2回接種です。1回目の予約時に、2回目の予約も医療機関に確認してください。
  2. 助成の接種期間を過ぎて受けてしまう。 確認した3市区はどれも2027年1月31日までで、期間外の接種は助成の対象外です（市川市のページ）。1月12日から受けるなら、2回目の日程まで逆算して予約してください。
  3. クーポン券・予診票・領収書を持たずに受けて、全額自己負担になる。 名古屋市は、クーポン券の提出がなければ全額自己負担と書いています。市川市は、領収書の写し（明細書のみは不可）が申請に必要です。受診前に持ち物を確認してください。
  4. 他の自治体の助成額を、自分の自治体にも当てはめてしまう。 同じ子ども向けでも、大田区2,000円、市川市1,500円、名古屋市は全額と、金額も対象年齢も違います。名古屋市は点鼻が対象外、市川市は注射と点鼻のどちらか一方、など細かい条件もあります。お住まいの自治体の当年度のページで確認してください。

よくある質問

インフルエンザの予防接種は健康保険で受けられますか。
受けられません。厚生労働省のQ&A（Q12）は、予防接種は病気に対する治療ではないため健康保険が適用されず、原則として全額自己負担で、費用は医療機関によって異なると説明しています（2026年10月20日確認）。65歳以上などの定期接種の対象者や、子ども向けの助成がある自治体では、その分だけ自己負担が下がります。
子どもは何回受ければよいですか。
厚生労働省のQ&A（Q9）では、13歳未満は2回接種です。6か月以上3歳未満は1回0.25mLを2回、3歳以上13歳未満は1回0.5mLを2回とされています。1回目が12歳で2回目が13歳になっていても、12歳として2回目を受けて差し支えないと書かれています。2回の間隔は医療機関の指示に従ってください。
1月12日からでもまだ受ける意味はありますか。
厚生労働省のQ&A（Q11）では、インフルエンザは例年12月〜3月頃に流行し、例年1月末〜3月上旬にピークを迎えるとされています。この記事の公開日は流行期の途中ですが、接種するかどうかは持病や体調によって変わります。受けるか迷う場合は、かかりつけの医師に相談してください。
自治体の助成は1月12日からでも使えますか。
使える場合があります。2026年10月20日時点で確認した大田区・市川市・名古屋市は、いずれも接種期間の終わりが2027年1月31日です。ただし、期間の終了日や申請の締切は自治体ごとに違うので、お住まいの自治体の公式ページで確認してください。期間外の接種は助成の対象外になります。
点鼻ワクチン（フルミスト）は何歳から何歳までですか。
添付文書（医薬品情報データベース KEGG MEDICUS に掲載された用法・用量）では、2歳以上19歳未満の者に0.2mLを1回、鼻腔内に噴霧するとされています。厚生労働省のQ&Aは、2023年に薬事承認された経鼻弱毒生ワクチンとして触れています。価格は医療機関ごとに違うため、受ける医療機関に確認してください。
高齢の親は費用がいくらかかりますか。
65歳以上は予防接種法に基づく定期接種の対象です（厚生労働省Q&A Q13）。大田区の2026年度（令和8年度）は自己負担2,500円で、生活保護受給者などは0円です（2026年10月20日確認）。金額は自治体で違うので、親御さんがお住まいの自治体に確認してください。
医療機関の窓口で払うお金と、あとで戻るお金の違いは何ですか。
自治体によって方式が違います。大田区は窓口でその場で差し引く方式、市川市は全額を払ってから領収書を添えて申請し、口座に振り込まれる方式です（2026年10月20日確認）。後者は申請の締切があるので、領収書を捨てないでください。

入園準備の持ち物リストと費用は約5,600〜8,700円｜無償化の範囲と毎月の実費

公開日 2027-02-16　更新日 2026-10-20

本記事にはアフィリエイト広告（PR）が含まれます。紹介した商品を購入されると、当サイトに報酬が入ることがあります。内容は運営者が調べて書いています。

保育園や幼稚園の入園が決まると、持ち物の準備と「毎月いくらかかるのか」の2つが同時に気になります。この記事では、こども家庭庁の幼児教育・保育の無償化の案内、神戸市・日野市・本宮市・箕面市・堺市の公式ページ、楽天市場の商品価格を2026年10月20日に確認し、入園前の一度きりの費用と、入園後の毎月の費用に分けて整理しました。

この記事でわかること・結論

  1. 入園準備の持ち物8品は、楽天市場の実例で約5,600円（安い側）〜8,700円（やや上の側）。 お昼寝布団セット、お昼寝バッグ、通園バッグ、名前スタンプ、名前シール、上履き、コップ袋、ランチ3点セットの合計で、送料と園指定の制服・用品は含みません。
  2. 無償化されるのは「利用料」だけ。 3〜5歳は利用料が無償、0〜2歳は住民税非課税世帯が対象で、通園送迎費・食材料費・行事費は保護者負担のままです。
  3. 入園後の毎月は、給食費と延長保育料が中心。 神戸市の公立保育所は3歳児クラスから給食費が月5,600円（主食1,100円＋副食4,500円）、日野市は副食費が月4,500円、本宮市の延長保育は月2,500円で、年間にすると数万円の差になります。

入園準備の持ち物と費用の全体像

入園準備は「園に置く物」「毎日持っていく物」「名前を付ける道具」の3つに分けると整理しやすくなります。持ち物の種類とサイズは園ごとに違うため、園から配られる持ち物表が基準です。ここでは多くの園で求められる8品を取り上げ、楽天市場の検索結果から、安い順に並べたときの価格の例を2つずつ示します。

合計の式は、安い側が 2,100＋980＋780＋200＋270＋580＋165＋550＝5,625円、やや上の側が 3,980＋1,100＋1,080＋352＋590＋790＋220＋605＝8,717円です。ここには、園が指定する制服・スモック・帽子、シーツ・タオルケット、着替えの衣類、おむつは入っていません。0〜2歳でおむつの持ち込みが必要な場合は、おむつの費用の記事で月額の目安を確認できます。

幼稚園の場合は、制服や指定のかばんなど園指定品が別に発生する園があります。金額は園ごとに大きく違い、公式な全国平均は確認できなかったため、この記事では数字を載せません。入園説明会の資料にある指定品の価格表を、表1の合計に足してください。

手作りか購入か

布製の通園バッグやコップ袋は手作りもできますが、手作りが安いとは限りません。楽天市場で、キルティング生地は10cm単位で165円の商品があり、1m買うと165円×10＝1,650円です（2026年10月20日取得）。完成品の通園バッグは780円からあるため、生地代だけで完成品を上回ります。持ち手の布、裏地、ミシン糸、型紙は別です。

表 2　手作りと購入の比較（2026年10月20日・楽天市場の掲載価格）
項目手作り購入
通園バッグキルティング生地1mで1,650円（165円×10）＋持ち手・糸780円〜（完成品・3WAY）
コップ袋生地代＋ひも（生地を余らせやすい）165円〜（完成品・綿のミニ巾着）

金額だけを比べると、枚数が少ないうちは購入のほうが安い、というのがこの価格例からわかる範囲です。手作りが向くのは、園が「指定サイズ」「指定の生地」を求めていて、既製品に合う物が見つからない場合です。縫う作業を楽しめる、すでに生地やミシンがある、という場合は費用以外の理由で選べます。

園が手作りを求めているのか、既製品でよいのかは、持ち物表の注意書きに書かれていることが多いので、先に確認してください。

無償化の範囲: 何が無料で何が残るか

幼児教育・保育の無償化は、2019年10月から始まりました。こども家庭庁の案内（2026年10月20日確認）によると、幼稚園・保育所・認定こども園などを利用する3歳から5歳の全てのこどもの利用料が無償になります。0歳から2歳は、住民税非課税世帯が対象です。

表 4　無償化の範囲（こども家庭庁・2026年10月20日確認）
項目対象・上限
3〜5歳の保育所・認定こども園・地域型保育利用料が無償
3〜5歳の幼稚園月額上限2.57万円。無償化の期間は満3歳になった後の4月1日から小学校入学前までの3年間
0〜2歳住民税非課税世帯が対象。第2子は半額、第3子以降は無償（保育所等を利用する最年長のこどもを第1子とカウント）
幼稚園の預かり保育「保育の必要性の認定」を受けると、利用日数に応じて月額1.13万円まで（満3歳から最初の3月31日までの住民税非課税世帯は1.63万円）
認可外保育施設等「保育の必要性の認定」を受けると、3〜5歳は月額3.7万円まで、0〜2歳の住民税非課税世帯は月額4.2万円まで
通園送迎費・食材料費・行事費無償化の対象外（保護者負担）
副食（おかず・おやつ等）の費用年収360万円未満相当世帯と、全ての世帯の第3子以降は免除

ここで注意するのは、「無償」が利用料に限られる点です。給食費のうち主食費・副食費、バス代、行事費、教材費は含まれません。さらに、幼稚園は月額上限2.57万円までの補助で、園の保育料が上限を超える部分は自己負担になります。

自治体が独自に上乗せしている例もあります。本宮市は令和8年度から、保育料の全額を市独自に助成して保護者負担を0円にし、3歳以上児の副食費も市独自の半額助成で0円としています（2026年3月19日更新の掲載を2026年10月20日に確認）。国の制度と自治体の上乗せは別なので、住んでいる市区町村の案内で確認してください。

入園後の毎月の費用: 自治体の実例

無償化の対象外になる給食費と延長保育料は、自治体や施設で金額が違います。公式ページで金額が読めた例を並べます。

表 5　給食費・延長保育料の自治体実例（令和8年度・2026年10月20日確認）
自治体給食費・副食費延長保育料・その他
神戸市（公立保育所）月5,600円（主食費1,100円＋副食費4,500円）。3歳児クラスから。給食を出した日数が月の半分以下なら半額保育標準時間外・時間内の延長は利用料表で別途。2歳児クラスまでは給食費が保育料に含まれる（2026年4月2日最終更新）
日野市（市立保育園）副食費は月4,500円。主食費（ごはん・パン）は市が負担延長保育料は施設ごとに時間・料金が違い、生活保護世帯・里親世帯・住民税非課税世帯は免除（2026年7月30日付ページ）
本宮市3歳以上児の副食費は市独自の半額助成で保護者負担0円延長保育（18時〜19時）は児童1人あたり月額2,500円。無償化の対象外で、承認されれば利用の有無にかかわらず発生

3つを比べると、給食費は月4,500円〜5,600円の幅、延長保育は月2,500円の例がある一方、自治体の助成で副食費が0円になる例もあります。つまり、近隣の自治体どうしでも負担が違うため、「全国の平均はいくら」という数字で予算を立てるのは危険です。

免除の仕組みも確認してください。堺市の令和8年度の案内では、副食費は「年収360万円未満相当世帯」（一般世帯は市町村民税所得割額57,700円未満、ひとり親世帯などは77,101円未満）と、小学校就学前のお子さんのうち第3子以降が免除です。4〜8月分は前年度の市町村民税、9〜3月分は当年度の市町村民税で判定するため、4〜8月が免除でも9月以降は免除でなくなる場合があります。箕面市は、副食費の第2子の軽減（半額）はないと案内しています。

判断の分岐: あなたはどれか

  • 園から持ち物表と指定用品のリストが届いている → 表1の品目を、指定サイズと照らし合わせて買う。指定外のサイズは買わない。
  • 布団・バッグを園が貸してくれる、またはレンタルがある → 購入は不要。レンタル料が月額になる場合は、購入価格と比べて月数で割る。
  • 3〜5歳で保育所・認定こども園 → 利用料は無償。月々は給食費と延長保育料の確認が中心。
  • 3〜5歳で幼稚園 → 月額上限2.57万円の補助。園の保育料が上限を超える部分と、預かり保育は別枠（上限1.13万円）。
  • 0〜2歳 → 住民税非課税世帯が国の無償化の対象。自治体の独自助成がないか、市区町村の案内を確認する。
  • 年収360万円未満相当、または第3子以降 → 副食費の免除の可能性がある。市区町村の申請・通知の時期を確認する。
  • 延長保育を毎日は使わない → 月額固定か日額かを園に聞き、固定なら申し込み自体を減らす。

2〜3月の準備スケジュール（5手順）

入園の日程や説明会は園・自治体ごとに違うため、日付は書きません。次の順番で進めると、買い直しを減らせます。

  1. 園の持ち物表を受け取り、品目・サイズ・数を書き出す。 手作り指定か既製品でもよいかも確認する。
  2. 指定サイズがある物（布団、バッグ、上履き）から先に買う。 上履きはお子さんの足のサイズを計ってから選ぶ。
  3. 記名が必要な物の数を数え、スタンプ・ネームテープ・シールを素材別に買う。 衣類は布用、硬い物は耐水・防水シール。
  4. 名前を付けてから、洗い替えの数を決める。 洗えない物には、洗濯・洗浄が難しくない付け方を選ぶ。
  5. 毎月の費用（給食費・副食費・延長保育料）を園・市区町村の案内で確認し、家計に入れる。 免除の対象かどうか、申請が要るかも同時に確認する。

よくある失敗5つと回避策

  1. 園の指定サイズを確認せずにお昼寝布団を買った。 布団の寸法やロッカー・袋の大きさは園ごとに違います。持ち物表を受け取ってから買ってください。
  2. 「3歳から無償」を給食費まで無料だと思っていた。 無償化は利用料のみで、神戸市の公立保育所では3歳児クラスから月5,600円の給食費がかかります。
  3. 延長保育を申し込んだまま使わず、毎月2,500円を払い続けた。 本宮市の案内では、承認されれば利用の有無にかかわらず発生します。使う日が少ない月は、申し込み方法を園に確認してください。
  4. 名前付け用品を一種類にそろえて、硬い物から名前がはがれた。 衣類にはネームテープ、コップ・水筒などは耐水・防水シールと、素材別に用意してください。
  5. 免除の判定が年度で変わることを知らず、予算を組み間違えた。 堺市の案内のように、4〜8月は前年度、9〜3月は当年度の市町村民税で判定する自治体があります。9月以降の負担が増える場合を、年間の予算に入れておいてください。

よくある質問

入園準備セットを買えば、持ち物はそろいますか。
そろわない場合があります。持ち物の種類・サイズ・指定の有無は園ごとに違い、園から配られる持ち物表が基準になります。楽天市場の2026年10月20日の検索では、巾着3点のランチセットが550円、お昼寝布団セットが2,100円からありましたが、布団のサイズが園の指定と合うかは別に確かめてください。
3歳になれば保育園・幼稚園の費用は全部無料になりますか。
全部は無料になりません。こども家庭庁の案内では、幼稚園・保育所・認定こども園を利用する3歳から5歳までの全てのこどもの利用料が無償化され、通園送迎費・食材料費・行事費は引き続き保護者の負担です（2026年10月20日確認）。神戸市の公立保育所では3歳児クラスから保育料が無償になり、給食費が月5,600円かかる例があります。
0〜2歳の費用も無償化されますか。
国の制度では、0歳から2歳までは住民税非課税世帯が対象です（こども家庭庁、2026年10月20日確認）。課税世帯は保育料がかかります。ただし本宮市のように、令和8年度から市独自で保育料の全額を助成して保護者負担を0円にしている自治体もあるため、住んでいる市区町村の案内で確認してください。
副食費（おかず・おやつ代）が免除されるのはどんな世帯ですか。
こども家庭庁の案内では、年収360万円未満相当世帯と、全ての世帯の第3子以降のこどもが免除の対象です。堺市の令和8年度の案内では、年収360万円未満相当を「一般世帯は市町村民税所得割額57,700円未満」としています。箕面市は第3子以降は無料で、第2子の副食費の軽減（半額）はないと案内しています（2026年10月20日確認）。
延長保育料は無償化の対象ですか。
本宮市の案内では、延長保育（18時から19時）は児童1人あたり月額2,500円で、市の保育料無償化の対象外です。しかも申し込みが承認されれば、実際に使わない月も発生すると書かれています（2026年3月19日更新の掲載、2026年10月20日確認）。使う日が少ないなら、一時的な利用の扱いがないか園に聞いてください。
名前付けは何から用意すればよいですか。
園の持ち物表で「記名が必要な物の数」を数えてから決めます。衣類・タオルは布用のネームテープやアイロンシール、コップや水筒などの硬い物は耐水・防水のお名前シール、小さな物が多いならスタンプ、と使い分けると無駄が出にくいです。楽天市場の2026年10月20日の検索では、スタンプが200円から、耐水シールのお試しサイズが200〜590円でした。
小学校の入学準備と何が違いますか。
小学校はランドセルや学用品が中心で、この記事の対象外です。入園準備は、お昼寝布団・着替え・コップ袋などの園生活用品と、毎月の給食費・延長保育料の見通しが論点になります。小学校の費用は、関連記事の「小学校の入学準備」で比べています。

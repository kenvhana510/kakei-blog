空気清浄機の電気代

本記事にはアフィリエイト広告（PR）が含まれます。紹介した商品を購入されると、当サイトに報酬が入ることがあります。内容は運営者が調べて書いています。

空気清浄機は「つけっぱなしが前提の家電」なので、1時間あたりの電気代が小さくても、月や年に直すと差がはっきり出ます。この記事では、シャープ・ダイキン・パナソニックの公式仕様ページに書かれた運転モード別の消費電力（W）を原文で確認し、電気代は全国家庭電気製品公正取引協議会の目安単価 31円/kWh で自分で計算しました。数字は2026年10月20日時点です。

この記事でわかること・結論

  1. 24時間つけっぱなしでも、静音〜中の段なら月54〜446円です。 3機種の公式値から計算すると、静音は月54〜223円、中（標準）は月167〜446円でした（30日換算、31円/kWh）。
  2. 電気代を決めるのはモードです。 シャープ FU-S50 は強49Wに対して静音2.6Wで、約19倍の差があります。強・ターボで回し続けると月1,094〜1,830円です。
  3. 「畳数」は新旧の基準を確認してから選びます。 パナソニックの案内によると、規格 JEM1467:2026 の基準で表示する機種があり、同社の F-PX70C は新基準19畳・旧基準31畳と並記されています。部屋の広さと同じか、それより大きい面積の機種を選ぶと、短い時間で清浄できます（JEMA）。

電気代の計算式と前提

電気代は「消費電力（W）÷1,000×使った時間（h）×単価（円/kWh）」で出ます。この記事の前提は次のとおりです。

  • 単価は 31円/kWh（税込の目安。全国家庭電気製品公正取引協議会、令和4年7月改定）。シャープとダイキンの公式ページも、同じ31円/kWhで1時間あたりの電気代を表示しています。
  • 1日は24時間、1か月は30日、1年は365日として計算します。
  • 金額は小数点以下を四捨五入し、公式ページの表示と1円未満でずれる場合があります。たとえばダイキンはターボの1時間を2.55円と表示していますが、82W×31円÷1,000 の計算値は2.54円です。
  • 表の消費電力は、各社が「モード別」で公表している値です。部屋の汚れ方に応じて風量を自動で変える「自動運転」の平均値ではありません。

たとえば消費電力13Wを24時間つけると、13×24÷1,000＝0.312kWh、これに31円をかけて1日 約9.7円です。以降の表は、すべてこの式で計算しています。

風量が小さいほど消費電力も小さくなりますが、空気を回す量も減ります。ダイキンは公式ページで「しずか」について、運転音を抑えた微風運転のため空気清浄・脱臭の能力は低下すると注記しています。静音は夜や在宅していない時間向けで、においや花粉が出た直後は、中以上に上げたほうが早く清浄できます。

使い方別の電気代: 静音＋中の組み合わせ

実際の家では、1日中同じモードで回すより、時間帯でモードを分けることが多くなります。ここでは「日中の8時間は中（標準）、残りの16時間は静音（しずか）」という仮の使い方で、1日と30日の電気代を計算しました。

表 3　日中8時間は中、16時間は静音にした場合（31円/kWh・仮の使い方）
機種1日の消費電力量1日30日
シャープ FU-S50（13W×8h＋2.6W×16h）約0.146kWh約4.5円約135円
パナソニック F-PX70C（7.5W×8h＋4.0W×16h）約0.124kWh約3.8円約115円
ダイキン MCK70Z（20W×8h＋10W×16h）約0.320kWh約9.9円約298円

この使い方なら、3機種とも月の電気代は115〜298円です。JEMAのQ&Aが示す「1日10円前後」とも近い水準です。反対に、花粉やペット、料理のにおいが気になる日に「強」を8時間追加すると、シャープでは強49W×8hの追加分だけで1日約12円（49×8÷1,000×31）、30日で約364円増えます。

判断の分岐: あなたはどれか

  • 月の電気代を200円以下に抑えたい → 中までで運転します。表1では、パナソニックの静音・中、シャープの静音・中がこの範囲です。
  • 寝室で夜だけ使う → 静音で8時間なら、シャープは1日約0.6円、パナソニックは約1.0円です（2.6W×8h、4.0W×8h を31円/kWhで計算）。
  • リビングで花粉やにおいを早く取りたい → 来客後や掃除後の1〜2時間だけ強にし、その後は中か静音に戻します。
  • 強を毎日長時間使う予定 → 月1,000円以上かかるので、適用床面積の大きい機種を中の段で使うほうが安く済みます。

加湿機能付きとの電気代の差

冬は加湿機能付きを検討する人も多いはずです。ダイキン MCK70Z の公式表は、同じ機種で「空気清浄運転」と「加湿空気清浄運転」の消費電力を並べています。

表 4　ダイキン MCK70Z の空気清浄運転と加湿空気清浄運転（2026年10月20日時点・31円/kWh・24時間）
モード空気清浄加湿空気清浄差（30日）
しずか10W（月約223円）10W（月約223円）0円
弱11W（月約246円）12W（月約268円）約22円
標準20W（月約446円）23W（月約513円）約67円
ターボ82W（月約1,830円）84W（月約1,875円）約45円

この機種は、加湿方式が気化エレメント回転式で、加湿運転のときも空気清浄（脱臭・集じん）運転が同時に動きます。そのため、加湿を足したときの電力の増え方は0〜3Wと小さく、標準で月約67円です。電気代だけを見れば、加湿機能付きを選んでも大きな負担にはなりません。

ただし、加湿には水の補給（タンク約3.4L）と加湿フィルターの手入れが必要です。加湿器単体の電気代は、加湿方式（スチーム式・気化式など）で大きく変わります。比較したい人は 加湿器の電気代の記事 も合わせて読んでください。

適用床面積の選び方（新旧の基準）

適用床面積は、日本電機工業会（JEMA）の規格 JEM1467 で決められた試験で「清浄できる部屋の広さ」を示した数字です。JEMAのQ&Aは、30分で清浄できるお部屋の広さとしており、使う部屋より大きい適用床面積の製品ほど、より短時間で空気を清浄できると説明しています。

適用床面積の基準には新旧があります（日本電機工業会の原文は未確認で、以下はパナソニックの案内によります）。パナソニックの公式FAQ（2026年10月20日閲覧）は、JEM1467:2026 の基準で、粉じん濃度を20％まで低減できる部屋の広さ（天井高2.5mで算出）と説明しています。同社の F-PX70C の仕様ページには、次のように新旧が並記されています。

表 6　適用床面積の表記の違い（2026年10月20日時点）
機種公式ページの表記8畳の清浄時間
パナソニック F-PX70C新基準 19畳（31㎡）／旧基準 31畳（51㎡）約10分
シャープ FU-S50〜23畳（38㎡）。『30分で、粉じん濃度1.25mg/m³から0.15mg/m³まで清浄』の旧基準の説明12分
ダイキン MCK70Z〜31畳（51㎡）。シャープと同じ旧基準の説明9分

同じパナソニックの F-PX70C で、旧基準31畳が新基準では19畳になります。新旧は直接比べられません。シャープやダイキンの旧基準の数字を、新基準の他社機種の数字と並べて「こちらのほうが広い」と読まないよう注意してください。

選ぶときの目安は、リビングの畳数以上を基本にすることです。たとえば12畳の部屋で使うなら、旧基準の表記なら18畳以上、新基準の表記なら12畳以上を探します（旧基準と新基準で、同じ機種の畳数は約1.6倍違うことがパナソニックの並記から読み取れます）。余裕のある機種を中の段で使えば、電気代を抑えながら清浄時間も短くできます。

JEMAのQ&Aは、集じん能力は空気を清浄する時間が初期の2倍以上になったとき、脱臭能力はにおいの除去率が半分になったときを交換の目安としています。年数は目安にすぎず、たばこや焼肉のにおいが強い部屋では早くなります。シャープの公式ページも、強いにおいの中で使うと数週間から数か月でフィルターからにおいが出て、交換が必要になる場合があると注記しています。

使い終わったフィルターは、ほとんどが一般ごみとして扱えますが、自治体によって処理方法が異なるため、お住まいの自治体で確認してください（JEMAのQ&A）。

花粉の時期の使い方

2月は花粉への備えを始める時期です。花粉対策のグッズ全般は 花粉対策グッズの記事 にまとめたので、ここでは空気清浄機の電気代に絞って使い方を整理します。

  1. 置き場所は玄関に近い部屋か、人がいる部屋にします。 帰宅後に衣類から落ちた花粉を、短時間の強運転でまず回収します。
  2. 強運転は帰宅後や掃除後の1〜2時間に限ります。 シャープなら強49Wを2時間で約3.0円（49×2÷1,000×31）です。
  3. 在宅中は中（標準）、就寝中は静音にします。 表3の組み合わせで、月115〜298円です。
  4. 機種に「花粉運転」などの専用モードがあれば試します。 ダイキン MCK70Z の機能一覧には「花粉運転」があります。消費電力の公式値は、通常のモードとは別に公表されていません。
  5. フィルターの汚れを月に1回点検します。 目詰まりすると清浄時間が延びるため（JEMAのQ&Aの交換目安）、電気代をかけて回しても効果が落ちます。

仮に花粉の時期を90日として、中（標準）の段で24時間運転したとき、シャープ FU-S50 は約870円、パナソニック F-PX70C は約502円、ダイキン MCK70Z（空気清浄・標準）は約1,339円です。体感できる効果は部屋の広さやドアの開け閉めの回数にも左右されるので、まず中の段で運転して、足りなければ強を足してください。

冬の暖房費と合わせた家計全体の見直しは、冬の電気代の記事 も参考になります。空気清浄機は暖房に比べて電気代が小さく、家計への影響は限られます。

ダイソンの電気代を調べるときの注意

「ダイソン 空気清浄機 電気代」で調べる人も多いので、確認できた範囲を正直に書きます。ダイソン公式の商品ページ（Dyson Purifier Cool Formaldehyde TP09、2026年10月20日閲覧）では、仕様欄が折りたたみ表示で、消費電力のW数を本文から取得できませんでした。そのため、この記事ではダイソンの電気代の数字は載せていません。

同じ公式ページで読み取れたのは、次の点です。フィルターは「一体型グラスHEPA・活性炭フィルター」で、H13規格のHEPAフィルターが0.3μmまでの粒子を99.97％捕集すると書かれています。また、ホルムアルデヒドを分解する触媒フィルターは、フィルター交換が不要と書かれています。ダイソンの空気清浄ファンは夏は送風機としても使える構造で、他社の据え置き型とは用途が違うため、電気代だけでなく、使いたい季節で比べてください。

ダイソンの電気代は、型番ごとの仕様欄にある最大・最小の消費電力（W）を確認し、本文の式（W数×24×31÷1,000）に入れると計算できます。たとえば10Wなら1日約7.4円、40Wなら約29.8円です。

電気代を試算して選ぶ手順（5手順）

  1. 置く部屋の畳数を決めます。 リビングが12畳なら、基準が旧基準か新基準かを確かめたうえで、12畳以上の機種に絞ります。
  2. 公式仕様ページで「モード別の消費電力」を探します。 強・中・静音の3段の数字が出ている機種を選ぶと、比べやすくなります。
  3. 使う時間帯を決めます。 たとえば「日中8時間は中、残りの16時間は静音」と決め、表3の式（W×時間の合計÷1,000×31円）に入れます。
  4. 電気代に本体価格とフィルターの費用を足します。 表5のように5年分の合計を出すと、安い機種と高い機種の差が見えます。
  5. 購入前に最新の仕様ページと価格を確認します。 仕様・価格は2026年10月20日時点です。型番の末尾（-W、-Hなど）は色の違いなので、同じ型番で比べてください。

よくある失敗5つと回避策

  1. 強運転のまま24時間回してしまう。 シャープなら月1,094円、ダイキンのターボなら月1,830円かかります。回避策は、強を帰宅後や掃除後の1〜2時間に限り、普段は中か静音に戻すことです。
  2. 電気代の安さだけで本体を選ぶ。 パナソニックの電気代の差は年約1,500円で、本体価格の差は約24,800円です。回避策は、表5のように5年分の合計で比べることです。
  3. 畳数の新旧基準を見ずに、他社と比べる。 パナソニック F-PX70C は旧基準31畳が新基準19畳です。回避策は、同じ基準で書かれた数字だけを比べることです。
  4. フィルターを替えずに使い続ける。 集じん能力は、清浄時間が初期の2倍以上になったときが交換の目安です（JEMA）。回避策は、公式の交換目安の年数をカレンダーに入れ、強いにおいのある部屋では早めに点検することです。
  5. 広すぎる部屋で小さい機種を強で回す。 適用床面積が足りないと、強にしても清浄に時間がかかり、電気代だけが増えます。回避策は、部屋の畳数以上の機種を選び、中の段で使うことです。

よくある質問

空気清浄機を24時間つけっぱなしにすると、電気代は1か月いくらですか？
静音〜中の段で運転した場合、公式の消費電力（2026年10月20日時点）と31円/kWhで計算すると、シャープ FU-S50 は静音 約54〜58円・中 約290円、パナソニック F-PX70C は静音 約89円・中 約167円、ダイキン MCK70Z は しずか 約223円・標準 約446円です（30日換算）。日本電機工業会（JEMA）のQ&Aも、空気清浄運転は1日中運転しても電気代は1日10円前後としています。
「強」や「ターボ」で回し続けると、いくらになりますか？
30日つけっぱなしの計算で、シャープ FU-S50 の強（49W）は約1,094円、パナソニック F-PX70C の強（57W）は約1,272円、ダイキン MCK70Z のターボ（82W）は約1,830円です。静音との差は、シャープで約19倍（49W÷2.6W）あります。強運転は長時間続けず、においや花粉が気になる時間だけにするのが現実的です。
使っていない間の待機電力はかかりますか？
シャープ FU-S50 は待機時消費電力 約0.3W、パナソニック F-PX70C も待機電力0.3Wと公式に書かれています（2026年10月20日時点）。0.3W×24時間×31円/kWh÷1,000 で1日約0.22円、30日で約7円、1年で約81円です。
加湿機能付きにすると、電気代はどれくらい増えますか？
ダイキン MCK70Z の公式表では、同じ段の消費電力が空気清浄運転と加湿空気清浄運転で、しずか 10W→10W、弱 11W→12W、標準 20W→23W、ターボ 82W→84W です。標準で24時間つけると、差は3W分で1日約2.2円、30日で約67円です。このほかに加湿の水の補給とフィルター手入れの手間がかかります。
適用床面積の「畳数」は、そのまま信じてよいですか？
パナソニックの案内によると、適用床面積は日本電機工業会の規格 JEM1467:2026 の基準で表示されており、同社の公式仕様では F-PX70C が新基準 19畳（31㎡）・旧基準 31畳（51㎡）と並記されています。同じ機種でも新旧で畳数が違うため、購入前に「どちらの基準の数字か」を確認してください。シャープ FU-S50 とダイキン MCK70Z のページは、2026年10月20日時点で『30分で清浄できる広さ』という旧基準の説明が書かれています。
フィルターは何年ごとに交換しますか？
機種ごとに違います。シャープ FU-S50 は静電HEPAフィルターと脱臭フィルターとも交換目安が約10年、パナソニック F-PX70C は集じんフィルターが約3.5年と公式仕様に書かれています（2026年10月20日時点）。JEMAのQ&Aは、集じん能力は空気を清浄する時間が初期の2倍以上になったとき、脱臭能力はにおいの除去率が半分になったときを交換の目安としています。
ダイソンの空気清浄機の電気代は？
ダイソン公式の商品ページ（2026年10月20日閲覧）では、消費電力の数字を本文から取得できませんでした。そのため、この記事では数字を載せていません。型番ごとの仕様欄で最大・最小の消費電力（W）を確認し、本文の式「W数×24×31÷1,000」に入れると、1日の電気代が出ます。
